## Ranked recommendation for cheap agent fleets

1. **DeepSeek V4 Flash direct API — best $/token.** $0.14/$0.28 per 1M (cache-hit $0.0028), 1M context, OpenAI+Anthropic API, 2,500 concurrency. A heavy agent fleet that would burn $10/day of Claude Sonnet runs on ~$0.5–2/day here. Caveat: DeepSeek announced a significant price increase — front-load usage and pin tooling to the (still cheap) cache-hit path.
2. **OpenCode Go $10/mo — best flat-rate fleet plan.** Pays $10, grants ~$60 of usage (6× multiplier) across DeepSeek V4 Flash/Pro, GLM-5.2, Kimi, MiniMax, Qwen, Grok 4.5 with one API key usable from any agent. DeepSeek V4 Flash currently gets 2× limits (~31,650 req/5h).
3. **OpenCode Zen PAYG — best safety-net + free models.** Zero-markup per-token pricing, free access to DeepSeek V4 Flash Free / MiMo-V2.5 Free / North Mini Code while promos last, $20 min top-up, spend caps — ideal fallback when Go quota is exhausted.
4. **QwenCloud Token Plan — best cheap multi-model + night discount.** Standard $18 (or Lite $6) includes qwen3.8-max, GLM-5.2 and deepseek-v4; 50% credits off 22:00–08:00 UTC+8 makes overnight agent fleets ~2× cheaper.
5. **Kimi Moderato/Allegretto — best long-context K3.** $19 gets K3-256k + K2.7 Code; $39 (Allegretto) adds K3 1M context + 6× HighSpeed — strong pick when fleet tasks need huge contexts.
6. **Z.AI GLM Coding Plan Lite $18 — GLM-5.2 at flat rate.** 2k credits/5h + 10k/wk, off-peak 50% — pair with DeepSeek/Qwen for model diversity.
7. **MiniMax Plus $20 — M3 agents + multimodal.** Good single-sub alternative to Z.AI if you want speech/image in the same quota.
8. **Prime Intellect PAYG — when you want one key to rule them all** (Anthropic + OpenAI + open models at list price) but no flat-rate discount.

Skipped for fleets: **GitHub Copilot / Cursor / Devin / Factory** are great IDEs/agents but their model access is product-bound (credits or IDE quotas, separate APIs for headless use); **Cohere has no coding plan** (pay-as-you-go only); **Alibaba $50 Coding Plan** is solid fixed-cost but undercut by OpenCode Go for the same models.
